# QRPatch · 文字标注 P0 实施方案

状态：**开发分支，不合并、不部署、不发布标签**。  
分支：`feat/text-annotation-layers`，基于 `main`。预计合并后的版本目标为 `v0.2.0-alpha.1`（仅计划）。

## 产品范围

QRPatch 从“替换真实二维码”自然扩展为“在海报中补充确定性的二维码说明文字”，而**不是通用海报设计平台**。

### 左侧：先选样式再添加

1. 多行文字输入（限 80 字，最多绘制 4 行），常见用语如“扫码报名”、“加入头马”。
2. 文字颜色：自定义颜色 + 5 个快捷色。
3. 五个样式：标题、描边、白底卡片、胶囊、说明。均为编辑器内 Canvas 矢量文字绘制。
4. “添加到画布”创建一个独立的文字图层，不绑定到二维码图层，也不覆盖背景。

### 画布：只负责位置与缩放

- 选中、拖拽、四角等比缩放；支持触控扩大命中范围。
- 保留图层排序、隐藏、复制、删除、撤销、重做。
- 文字选中时不展示不相关的二维码形状、裁切和图片缩放控件。
- 左侧继续添加新文字；右侧可精确设置 X/Y、尺寸及修改错字。
- 每个文字图层保留 `text`, `textStyle`, `color`, `baseW`, `baseH`, `x`, `y`, `w`, `h`, `lock`, `visible`。

## 图层渲染与清晰度

Canvas 使用 `fillText` / `strokeText` 在每次显示和 PNG 导出时重新绘制文本，内部保留文本与样式信息，不预先光栅化成 PNG/SVG。缩放参数来自 `w/baseW`、`h/baseH` 变换，输出仍沿用原始海报像素尺寸。

白底、胶囊样式的卡片背景只属于文本图层。二维码仍按既有图层及安全白边逻辑独立处理。背景滤镜不作用于图层。

## 非目标（暂不做）

- SVG 文件导出、任意路径字形转换或字体上传
- 旋转、富文本、逐字样式、复杂自动布局和贴纸系统
- 文本与二维码自动编组、独立“二维码卡片”模板
- 后端存储或 AI 文案生成
