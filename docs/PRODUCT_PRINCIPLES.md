# QRPatch — Product principles

## Positioning

**AI creates the art. QRPatch fixes the QR.**

QRPatch is a narrowly scoped open-source web tool for fixing invalid or inaccurate QR-code graphics generated by AI. Users overlay real QR images manually instead of trying to persuade image-generation models to draw accurate data patterns.

The product is judged by whether users can complete this sequence quickly:

1. Upload an AI-generated image.
2. Identify/cover the bad QR area.
3. Upload a valid QR and drag/resize it into place.
4. Export the original-size image.

## Experience principles

- **Result first.** The editor, not onboarding, takes center stage.
- **Zero configuration.** No account, API key, AI model, database, or server upload.
- **Precision without complexity.** Large handles, easy drag/resize, clear alignment and numbers when necessary.
- **QR correctness beats decoration.** Default square, quiet zone, opaque white backing, contain-fit; circle crop only for ordinary images.
- **No Photoshop sprawl.** Additional image edits must directly improve QR replacement.
- **Trust through transparency.** Say “local-only” because it is local-only; don't claim universal scan success before the exported image is actually tested.

## Open-source presentation

README hero should show the real editor screenshot (not a generated mock), a 3-step product flow, concise features, quick start, privacy promise, and links to docs/license/contributing. Avoid excessive badges and decorative emoji. Maintain clear limitations.

## Release gate

Do not tag as stable until practical import/drag/export and scan reliability checks are complete on browsers. An early alpha tag is appropriate when behavior has been manually validated.
